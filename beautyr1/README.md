# VALINYTSKYI AGENCY — mobile landing RU / UA

Готовый репозиторий для загрузки в GitHub Pages.

## Страницы

- `index.html` — русская версия сайта
- `ua/index.html` — украинская версия сайта
- `thanks/index.html` — служебная страница после оплаты на русском
- `ua/thanks/index.html` — служебная страница после оплаты на украинском
- `assets/author-photo.png` — исходная фотография автора без генерации
- `assets/config.js` — Telegram, консультация и временно отключённые ссылки оплаты

## Что реализовано

- Только мобильный макет: страница ограничена шириной 430 px.
- Исходная цветовая стилистика: чёрный / красный / белый.
- Фотография автора на первом экране и в блоке об авторе.
- Сохранены исходные блоки лендинга; добавлены программа на 5 дней и блок автора.
- В блоке автора указано: 4+ года работы с beauty-нишей.
- Тарифы: «Я всё сама / Я все сама» — 100 $, VIP — 200 $. Платежные ссылки временно отключены.
- Форма содержит только тариф, имя и контакт.
- Кнопка заявки отправляет контакт в Telegram-группу. Переход на оплату временно отключён до добавления новых платежных ссылок.
- Кнопка консультации есть на лендинге, внутри формы и на служебных страницах.

## Осталось заполнить

Откройте `assets/config.js` и вставьте ссылку на бота консультаций:

```js
consultation: 'https://t.me/USERNAME_ВАШЕГО_БОТА'
```

## Публикация на GitHub Pages

Загрузите содержимое архива в корень репозитория и включите:

- `Settings → Pages`
- `Deploy from a branch`
- ветка `main`
- папка `/(root)`

## Безопасность

В тестовой версии токен Telegram-бота расположен в публичном файле `assets/config.js`. Перед рабочим запуском замените токен и вынесите отправку заявок на backend.


## Исправление отображения лидов в Telegram

В этой версии исправлена отправка текста в Telegram:

- вместо символов `\n` в сообщении теперь используются настоящие переносы строк;
- включено аккуратное HTML-форматирование Telegram: подписи полей отображаются жирным;
- пользовательские значения экранируются, чтобы имя или контакт не ломали формат сообщения.


## Meta Pixel

В сайт установлен Meta Pixel с ID `1611532619914824`.

События:
- `PageView` — на русской и украинской посадочных страницах и служебных страницах;
- `Lead` — после заполнения формы и нажатия кнопки заявки на RU/UA лендингах.
